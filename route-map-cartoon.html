    成都至拉萨完整路线

    主干逻辑 成都沿 G318 到理塘，中途按需选择香格里拉线和南极洛线，再经德钦、盐井到芒康接回 G318，最终抵达拉萨。
    1. 01

      G318 主干 · 成都至理塘

      成都 → 康定 → 新都桥 → 雅江 → 理塘

      先沿川藏南线进入高原，理塘是继续走 G318 或转入南部支线的分岔点。

    2. 可选 A

      中途可选 · 香格里拉线

      理塘 → 稻城 → 亚丁 → 乡城 → 云南香格里拉

      选择后会离开 G318；若不去南极洛，可从香格里拉直接转 G214，经德钦、盐井前往芒康。

      可独立选择
    3. 可选 B

      中途可选 · 南极洛线

      香格里拉 → 维西 → 巴迪乡 → 南极洛

      通常建立在香格里拉线之上；完整游览可能至少需要 2 天，核心景观还涉及高海拔长距离徒步。此处只保留行车关系，暂不排具体日期。

      至少预留 2 天
    4. 02

      滇藏回接线 · 返回 G318

      维西 / 香格里拉 → 德钦 → 盐井 → 芒康

      不去南极洛时从香格里拉进入 G214；去南极洛后返回维西方向，经 S237 北上德钦，再沿 G214 在芒康接回 G318。

    5. 03

      G318 主干 · 芒康至拉萨

      芒康 → 左贡 → 八宿 → 然乌 → 波密 → 鲁朗 → 林芝 → 拉萨

      重新回到川藏南线，继续经过藏东峡谷、冰川和林芝河谷抵达拉萨。

    6. 抵达后

      拉萨周边可选支线

      纳木错线 / 羊卓雍措线

      两条都以拉萨为起终点，等主线日期确定后再决定是否二选一或全部保留。
